# Document Navigator v1.0.0

First GitHub distribution release of the Document Navigator sidebar for RemNote.

- H1–H5 outline with search and click-to-jump.
- Word-style Show Heading Levels: choose Show H1 and still expand deeper headings with arrows.
- Reset expansion, compact rows, full-height scrolling and saved level preference.

Download the attached Document-Navigator-v1.0.0.zip for submission through RemNote's Plugins > Build > Upload plugin. Do not upload GitHub's automatically generated Source code (zip).

RemNote review and approval are required before installation from the plugin page. This GitHub release alone does not install or publish the plugin in RemNote.
