# Changelog

## 1.0.0

First GitHub distribution release, retaining the latest local prototype's navigation behavior.

- Native H1–H5 outline, search, folding and jump to heading.
- Word-style expansion presets: deeper levels remain reachable through arrows at Show H1.
- Full-height panel fixes and compact heading rows.
- GitHub Actions build, typed source, automated tests and upload-package verification.
- Repository and author metadata generated from the actual GitHub repository.
- New owner-scoped plugin ID to keep this v1.0.0 release separate from the previous local prototype.
- Flat RemNote upload ZIP without Windows launchers or a bundled server.
